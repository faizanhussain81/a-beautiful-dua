# Where My Duas Bloom ♡

A romantic, two-scene garden experience with no photos and no music.

## Journey
1. A flower-covered open garden entrance appears with a glowing, pulsing heart button.
2. Pressing the heart transitions to the cherry-blossom pathway, with drifting petals and a gentle moving garden scene.
3. Press the second heart button to reveal the personal love letter.

## Files
- `index.html` — page structure and letter
- `css/style.css` — responsive styling and animations
- `js/script.js` — heart-button interactions and falling petals
- `assets/images/love-garden.png` — first garden entrance
- `assets/images/cherry-blossom-pathway.png` — second garden scene

## Publish
Upload the contents of this folder to the root of a GitHub repository. Enable GitHub Pages from the `main` branch and `/(root)` folder.
